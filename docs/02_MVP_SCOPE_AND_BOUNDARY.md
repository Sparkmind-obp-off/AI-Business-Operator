# 02 — MVP Scope & Boundary

## MVP objective

Prove that real demand can be collected from multiple sources, converted into structured opportunities, and used to drive concrete business actions.

## MVP capabilities

1. Source configuration.
2. Scheduled/manual ingestion.
3. API and automation-provider adapters.
4. Raw-event storage.
5. Demand normalization.
6. Duplicate detection.
7. Evidence and provenance tracking.
8. Demand classification.
9. Opportunity scoring.
10. Opportunity database.
11. Search/filter/dashboard.
12. AI-generated opportunity summary.
13. Human approval before external action.
14. Action/task generation.
15. Feedback capture.

## Explicitly deferred

- Fully autonomous sales outreach.
- Unrestricted browser automation.
- Platform-specific unofficial scraping as a guaranteed service.
- Complex multi-agent autonomy.
- Voice-first execution as a prerequisite for MVP.

## MVP success criteria

A user can select a target market, ingest signals, see why an opportunity is ranked highly, inspect source evidence, and generate a practical next action without manually researching every source.
